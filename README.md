# Data Analyst Internship - DecodeLabs

This repository contains the data analytics tasks completed during the DecodeLabs Industrial Training Program 2026.

## Project 1: Data Cleaning & Preprocessing
- Cleaned and structured raw datasets.
- Handled missing values, duplicates, and data formatting using standard analytical tools.

## Project 2: Exploratory Data Analysis (EDA)
- Performed statistical summary and trend analysis.
- Visualized key business metrics to identify growth patterns and anomalies.

## Project 3: SQL Data Analysis
- Performed database-driven analysis on the company's order dataset.
- Executed optimized SQL queries for filtering bulk operations, evaluating product performance, and analyzing marketing referral channels.

### Folder Structure:
- `project1/`: Contains documentation and files for data cleaning.
- `project2/`: Contains files and insights for exploratory data analysis.
- `project3/`: Contains SQL logic using Excel to evaluate product performance, status distributions, and referral channels.
- `tasks/`: Contains the original task details and PDF guidelines provided by DecodeLabs.
